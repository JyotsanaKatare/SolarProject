# AP Power Energy Solutions – Solar Website

A fully responsive lead-generation website built for a solar energy company, 
featuring smooth animations, automated email inquiries, and real-time 
WhatsApp integration.

🔗 Live Demo: https://appowers.in/

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Framer Motion, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Email:** Resend API
- **Animations:** Framer Motion

---

## ✨ Features

- Multi-section layout: Why Solar, Services, Testimonials, FAQs, About, Contact
- Smooth scroll animations using Framer Motion
- Automated client inquiry emails via Resend API
- WhatsApp chat widget for real-time customer engagement
- Fully mobile-responsive design
- Cross-browser compatible

---

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/JyotsanaKatare/SolarProject

# Install dependencies
npm install

# Run the app
npm run dev
```
